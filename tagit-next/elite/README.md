# TAG elite

طبقة متابعة موازية لـTAGit NEXT: فرصة محفوظة، حالة مفسرة، جودة بيانات، محاكاة تنفيذ، وواجهة عربية RTL. **إصدار بحثي/موازٍ، لا استراتيجية تداول مثبتة.**

## التشغيل

يتطلب Node 24. لا حزم npm خارجية للوحدة.

```sh
cd tagit-next/elite
npm test
npm run replay
npm run serve
```

تفتح المعاينة على `http://localhost:8790/elite/`. إعادة التشغيل تستخدم `../data/study` و`discovery-audit.json` و`study-manifest.json` وتقويم المزود المحفوظ. تتحقق بصمات كل ملف قبل التحليل. مخرجات الواجهة مضغوطة لكل جلسة وتقرأها المتصفحات عبر DecompressionStream.

لتشغيل الخدمة المدمجة:

```sh
cd tagit-next/quote-service
npm test
npm start
```

واجهة `/elite/` وواجهات قراءة فقط:

- `GET /api/elite/status`
- `GET /api/elite/opportunities`
- `GET /api/elite/timeline?id=<opportunity-id>`

يحصل الرصد الجديد على أدلة الماسح أثناء استدعاء `/api/scanner`. لا يغيّر شروطه أو نتيجة NEXT. المتابعة الإضافية تستخدم الموصل نفسه للأسهم التي خرجت من shortlist. لا يُفعّل عاملًا دائمًا أو تداولًا آليًا تلقائيًا.

## الإعدادات

`TAG_ELITE_DB`: مسار SQLite. الافتراضي `/tmp/tag-elite.sqlite` **مؤقت**؛ صالح للمعاينة، ليس بوابة إطلاق دائم. استخدم قرصًا مثبتًا لثبات السجل ثم اختبر إعادة نشر واستعادة قبل إعلان الديمومة.

`TAG_ELITE_CONFIG_JSON`: overrides لخادم موثوق فقط. أمثلة: `maxMarketCap`، `exchanges`، `shariaRequired`، `periods`، `execution`. يتغير runId تلقائيًا مع بصمة الإعدادات، فلا يُعاد وسم الماضي. الموصل الحي الأصل يزوّد NASDAQ دون 100 مليون فقط؛ توسيع الكون خارج ذلك يتطلب تغذية مؤهلة إضافية، ولا يزعم هذا الإصدار أنه وسّع تغطية NEXT. تضييق الأهلية متاح.

إعدادات Alpaca الحالية تبقى في الخادم فقط. لا تحتاج الواجهة مفاتيح. كل endpoints الجديدة GET فقط؛ لا API عامة لتغيير الإعدادات أو إدخال سجلات. إعدادات الإدارة عبر بيئة الخادم بصلاحيات المنصة.

## الحفظ وإعادة الإنتاج

SQLite WAL، معاملات `BEGIN IMMEDIATE`، مهلة قفل، مفاتيح محتوى تمنع تكرار البيانات، triggers تحمي أول اكتشاف. checkpoints داخل المعاملة نفسها تحفظ حالات الرمز والجلسة. كل تشغيل له إصدار وبصمة إعداد ومصدر، وكل تجربة مسجلة قبل حساب نتيجتها. تغير feed ينشئ فرصة مختلفة؛ IEX لا يتحول SIP.

للاستئناف التاريخي:

```sh
TAG_ELITE_REPLAY_DB=/absolute/persistent/elite-replay.sqlite node scripts/replay.mjs
```

إعادة تشغيل الأمر بنفس المدخلات تُعيد المرور على النقل وتزيل التكرار بالمفاتيح؛ لا تكرر السجلات. job cursor محفوظ على مستوى الجلسة، وليس ضمان exactly-once لعمليات خارجية.

## المراقبة والرجوع

راقب `lastObservedAt`, `lastError`, `busy`, `computeMs`, `processedBars`, `invalidBars`, `inputs`, `opportunities`, `transitions`, `storage`, `durabilityVerified`. عند تعطل التاريخ المتابع، لا تُنشأ بيانات تعويضية. توقف المصدر يظل واضحًا. حالات الخطأ مصنفة ولا تعرض مفاتيح أو headers.

للرجوع: واجهة NEXT القديمة لم تتغير، ويمكن العودة إليها فورًا. يمكن إعادة نشر commit Render السابق `8f02f78655bf37bac089c80f16a4f3c785b6e710`، أو إلغاء تكامل server/bridge/http مع إبقاء ملفات المحرك الأصلية المجمدة دون تغيير مع إبقاء وحدة elite وأرشيفها. لا تحذف SQLite. احفظ نسخة قرص قبل تعديل schema؛ الترحيل الحالي إضافي لا يغيّر جداول NEXT.

## خطة الإطلاق وحالة الإنجاز

| المرحلة | الحالة |
|---|---|
| حفظ وجودة البيانات | منفذة برمجيًا واختُبرت محليًا؛ الديمومة التشغيلية متوقفة على قرص دائم والتحقق منه |
| محرك الحالات الموازٍ | منفذ؛ NEXT دون تعديل قواعد الاكتشاف؛ المعاينة تشمل الأرشيف والرصد عند الطلب |
| محاكاة 3 عائلات | منفذة، مع تكاليف/كمية/فجوات؛ أهلية الأرشيف تمنع اعتماد نتائج تداول |
| ترقية قواعد تدعمها نتائج مستقلة | **لم تتم**؛ لا يوجد اختبار مستقل مؤهل يؤيد الترقية |

## القيود التي لم تُخفَ

- لا تغذية صفقات مبادرة/دفتر أوامر أو OFI موثوق.
- لا مصدر متصل لتاريخ القيمة السوقية/float/الشرعية أو إجراءات الشركات؛ مخططات أحداث واختبارات دعمها موجودة، والقيم غير المتاحة تبقى مجهولة.
- لا سجل وصول أخبار الأرشيف، ولا backtest تأثير أخبار.
- لا أرشيف كامل للتداول الممتد؛ تحليل مسارات premarket والانعكاس عند الافتتاح لم يُثبت.
- لا كون مؤهل تاريخي شامل لحساب الفرص المفقودة أو مقام التزامن.
- لا قاعدة مشتركة متعددة الخوادم. SQLite مناسب لعامل/عدة عمليات على القرص نفسه؛ توزيع متعدد المضيفين يحتاج قاعدة خادم/معمارية أخرى.
- أمان الإضافة لا يصلح تلقائيًا كل تصميم النقاط القديمة، ومختبر NEXT القديم يظل كما هو.
- لا اعتماد للاستراتيجية أو وعد دقة/عائد/تعويض خسائر.
