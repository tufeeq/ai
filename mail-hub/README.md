# مركز البريد (Mail Hub)

بريد مجاني بالكامل على خادمك، مبني من برمجيات مفتوحة المصدر فقط، ويخدم كل مشاريعك من مكان واحد.

| الخدمة | الأداة | الرابط المقترح | ماذا تقدّم |
|---|---|---|---|
| خادم البريد | [Stalwart](https://github.com/stalwartlabs/stalwart) | `mail.tryn.cc` | صناديق بريد بنطاقاتك، استقبال وإرسال، DKIM وSPF وDMARC تلقائيًا، فلتر رسائل مزعجة، حظر آلي لمحاولات الاختراق، لوحة إدارة |
| البريد عبر المتصفح | [Roundcube](https://github.com/roundcube/roundcubemail) | `webmail.tryn.cc` | قراءة البريد وكتابته من المتصفح، والجوال يعمل عبر IMAP |
| البريد التسويقي | [listmonk](https://github.com/knadh/listmonk) | `lists.tryn.cc` | قوائم مشتركين، حملات، قوالب، إلغاء اشتراك بنقرة واحدة، إحصاءات فتح ونقر، معالجة الارتداد |
| إعادة تعيين كلمة المرور | خدمة `mailer/` في هذا المجلد | `mailer.tryn.cc` | واجهة برمجية لكل مشاريعك: رابط إعادة تعيين آمن، إشعار تغيير كلمة المرور، ورسائل تلقائية فردية |

كل شيء يعمل على خادم Dokploy نفسه، ولا اشتراك ولا رسوم إرسال.

## الأمان في خدمة إعادة التعيين

- **الرابط:** 256 بت عشوائية، ويُخزَّن منه بصمة SHA-256 فقط؛ لو سُرقت قاعدة البيانات لا يمكن استخدام أي رابط.
- **استخدام واحد ومدة محدودة:** 30 دقيقة افتراضيًا (5–120 حسب المشروع)، والاستهلاك ذرّي فلا يُستخدم الرابط مرتين حتى مع طلبين متزامنين.
- **أحدث رابط فقط يعمل:** طلب جديد يلغي الروابط السابقة لنفس البريد.
- **منع الإغراق:** 3 طلبات لكل بريد كل 15 دقيقة، و60 طلبًا في الدقيقة لكل مشروع، و300 رسالة عامة في الساعة.
- **عزل المشاريع:** لكل مشروع مفتاح خاص (يُخزَّن مُبصَّمًا ويظهر مرة واحدة)، ورابط مشروع لا يعمل في مشروع آخر.
- **رابط ثابت:** عنوان صفحة إعادة التعيين يُحدَّد عند تسجيل المشروع، فلا يمكن لمن يسرق المفتاح توجيه الروابط إلى موقع آخر.
- **الإرسال مشفّر:** عبر منفذ 587 مع STARTTLS إلزامي والتحقق من الشهادة.
- **سجل تدقيق** بلا عناوين بريد صريحة (بصمات فقط)، يُحذف بعد 90 يومًا.

## واجهة المشاريع

كل الطلبات `POST` بصيغة JSON مع الترويسة `Authorization: Bearer <مفتاح المشروع>`.

| المسار | المدخلات | النتيجة |
|---|---|---|
| `/v1/password-reset` | `email`، واختياريًا `user_id` و`name` و`locale` (`ar`/`en`) | `202` وتُرسل الرسالة |
| `/v1/password-reset/verify` | `token` | `200` مع `email` و`user_id`، أو `410` إن انتهى أو استُخدم |
| `/v1/password-reset/consume` | `token` | `200` مرة واحدة فقط، ثم `410` |
| `/v1/notify/password-changed` | `email`، `name`، `locale` | `202` |
| `/v1/send` | `to` (مستلم واحد)، `subject`، `html` و/أو `text`، `reply_to` | `202` |

**التدفق في مشروعك:**
1. نموذج «نسيت كلمة المرور»: إن كان المستخدم موجودًا استدعِ `/v1/password-reset`، واعرض للزائر الرسالة نفسها دائمًا («إن كان البريد مسجّلًا ستصلك رسالة») حتى لا يُعرف من المسجّل.
2. صفحة إعادة التعيين (`reset_url?token=…`): استدعِ `verify` لعرض النموذج.
3. عند الحفظ: استدعِ `consume`، وإن نجح احفظ كلمة المرور الجديدة (مُبصَّمة بـ argon2 أو bcrypt) لـ `user_id`، وأنهِ الجلسات الأخرى، ثم `notify/password-changed`.

أمثلة جاهزة: [`clients/node-reset-example.mjs`](clients/node-reset-example.mjs) و[`clients/python_reset_example.py`](clients/python_reset_example.py).
