# نُطق (Nutq) — قلها بالعربي

أداة بسيطة لمن لا يتكلم العربية: يكتب كلمة أو جملة إنجليزية فيحصل على:

- الترجمة العربية مشكولة (بالصيغة المنطوقة: بلا حركات إعراب في أواخر الكلمات).
- النطق بحروف إنجليزية، مثل `shukran jazeelan`.
- الصوت من أصوات Azure العصبية (سعودي، إماراتي، مصري — ذكر وأنثى) بسرعة عادية وبطيئة.
- كل كلمة على حدة مع معناها وصوتها، ونصائح للأصوات الصعبة في الجملة.

## كيف تعمل

| الجزء | من يقوم به |
|---|---|
| الترجمة والتشكيل | AI Hub (`ai.tryn.cc`) عبر `/v1/chat/completions` — أو أي خدمة متوافقة مع OpenAI |
| النطق بالحروف الإنجليزية | قواعد ثابتة في `src/translit.mjs` تُبنى على التشكيل، فلا تعتمد على النموذج. إن جاءت الترجمة بلا تشكيل كافٍ يُستخدم نطق النموذج |
| الصوت | Azure AI Speech (REST) |
| التخزين المؤقت | كل ترجمة وكل ملف صوت يُحفظ في `/data`، فالعبارة المكررة لا تُكلّف Azure ولا AI Hub مرة ثانية |

الحماية: الصوت لا يُولَّد إلا لنص خرج من ترجمة محفوظة (لا يمكن لأحد استعمال مفتاح Azure لقراءة نص عشوائي)، مع حدّ للطلبات لكل زائر، والمفاتيح لا تصل إلى المتصفح أبدًا.

## النشر على Dokploy

**1) مفتاح Azure Speech**
في بوابة Azure: **Create a resource ← Speech** (أو استخدم مورد Speech / AI Services موجود). من صفحة **Keys and Endpoint** خذ `KEY 1` و `Location/Region` (مثل `uaenorth` أو `westeurope`). الطبقة المجانية F0 تكفي للبداية.

**2) مفتاح AI Hub**
افتح `https://ai.tryn.cc/admin` ← أنشئ مفتاحًا جديدًا باسم `nutq` ومشروع `general`. يظهر مرة واحدة فقط.

**3) الخدمة في Dokploy**
- **Projects ← Create Project** باسم `nutq` ← **Create Service ← Compose** (النوع **Docker Compose**).
- المصدر: GitHub · `tufeeq/ai` · الفرع `claude/nutq` (ثم `main` بعد الدمج) · Compose Path: `./nutq/docker-compose.yml`.
- تبويب **Environment**:

```env
AI_API_KEY=مفتاح-AI-Hub
AZURE_SPEECH_KEY=مفتاح-Azure
AZURE_SPEECH_REGION=uaenorth
```

- تبويب **Domains**: الخدمة `web`، المنفذ `8080`، HTTPS بـ Let's Encrypt، والنطاق مثلًا `nutq.tryn.cc` (أضف سجل A في Namecheap يشير إلى IP الخادم).
- اضغط **Deploy**، ثم افتح `https://nutq.tryn.cc/health` — يجب أن ترى `"tts":true,"ai":true`.

لا تضع أي مفتاح في المستودع؛ المستودع عام.

## متغيرات البيئة

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `AI_BASE_URL` | `https://ai.tryn.cc/v1` | خدمة الترجمة |
| `AI_API_KEY` | — | مفتاح AI Hub |
| `AI_MODEL` | `gpt-4o-mini` | AI Hub يحوّله إلى نموذجه |
| `AI_TIMEOUT_MS` | `180000` | النموذج يعمل على المعالج فيحتاج وقتًا |
| `AZURE_SPEECH_KEY` / `AZURE_SPEECH_REGION` | — | مورد Azure Speech |
| `AZURE_SPEECH_ENDPOINT` | — | بديل عن المنطقة لنطاق مخصص |
| `DEFAULT_VOICE` | `ar-SA-HamedNeural` | الصوت الافتراضي |
| `MAX_INPUT_CHARS` | `200` | أقصى طول للنص |
| `TRANSLATE_RPM` / `AUDIO_RPM` | `10` / `60` | حدّ الطلبات في الدقيقة لكل زائر |

## حدود يجب معرفتها

- **جودة الترجمة من AI Hub أقل من النماذج الكبيرة.** النموذج الافتراضي صغير (`gemma3:4b`) وقد يخطئ في التشكيل أو اختيار الكلمة، وكل ترجمة جديدة قد تأخذ من ثوانٍ إلى دقيقة. الترجمات المحفوظة فورية. إن احتجت جودة أعلى غيّر `AI_BASE_URL` و `AI_API_KEY` و `AI_MODEL` إلى خدمة أقوى دون تعديل الكود.
- النطق بالحروف الإنجليزية دقيق بقدر دقة التشكيل الذي يعطيه النموذج.
- اللهجة السعودية تُكتب كما تُنطق، وأصوات Azure تقرأ بالفصحى أو بلهجة منطقتها؛ قد يختلف الصوت قليلًا عن اللهجة المكتوبة.
