# TAG10

TAG10 is an independent probabilistic state-intelligence rebuild for early mover discovery.

Core principles:
- State transitions instead of one composite momentum score
- Evidence graph with explicit missing-data handling
- Path probabilities: +10%, +20%, +40%, failure, halt
- Tradeability separated from prediction
- Strict Sharia gate and ABSTAIN state
- Dynamic targets derived from path probabilities
- Walk-forward validation required before production promotion

Run engine tests with Node: `node tag10/test-engine.js`.
